  **What exists.** `RogueTrader.AI` (pure C#, references only `RogueTrader.Simulation` for `ShipInput`): `PirateController : IShipController` is a deterministic state machine Idle / Patrol / DetectTarget / Chase / Attack / Evade / ReturnToPatrol (+ terminal Dead). It reads a read-only `AiWorldView` (self snapshot, capabilities, other ships, obstacles) once per 60 Hz tick and emits only the same `ShipInput(Thrust, Turn, Fire)` a player produces, so turn rate, acceleration, speed cap, energy and cooldown stay enforced by `WorldSimulation`. Behaviour: nearest-hostile acquisition (ordinal-id tie break) with a seeded reaction delay, lead-aimed intercept pursuit, standoff range management with hysteresis and closing-speed braking, fire only when aligned/in range/with energy, damage reception (provoked from beyond detection range), flee at low health and re-engage only when recovered, arrive-style patrol/return with no assumed drag. Randomness is a fixed SplitMix64 (`DeterministicRng`) seeded per controller; no clocks or `System.Random`. `SimulationAiViews` copies simulation state into immutable views.

  **Data.** All tuning is in `data/ai/pirate_ai.json`, `evidenceClassification: NEW` ([data plan](../../../data/ai/IMPLEMENTATION_PLAN.md)). Every number is a NEW/provisional invention; none is a recovered original controller value.
