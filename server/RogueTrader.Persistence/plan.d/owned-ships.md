-   Owned ships (branch `claude/project-thread-kv5jsp`, Steve's request on PR #112, November 3, 2026). Profile schema 6 adds `OwnedShips` (hull id to parked condition, at most one of each hull). `ShipHullId` stays the active ship and `Ship` its condition. Invariants: the active ship is owned, an owned set always has an active ship, and the active entry is never parked. Migration V5ToV6 makes the schema 5 hull the only owned ship and changes nothing else. `FileProfileRepository` keeps a byte copy of any pre-migration file as `<id>.profile.schema<N>.json` before the first newer write, and never overwrites it. New transaction kinds: `BuyShip` (at a station, price from `IPriceSource.TryGetShipPrice`, refused with `ShipAlreadyOwned`) and `ShipDestroyed` (no station; the active hull only, else `ShipNotActive`; charges `DestructionPenaltyPercent` = 20% of the wallet rounded down, resets the active ship to the spawn and keeps inventory, upgrades and owned ships). `SelectShipAsync` is a non-ledger change like ship saves and refuses `ShipNotOwned`. `SaveShipConditionAsync` now refuses hull 0. Evidence: `tests/Unit/Persistence/OwnedShipsTests.cs` and `tests/Unit/Trading/OwnedShipSessionTests.cs`. Not done: the 12 original hulls (they wait for G10's `OriginalShipPhysics`), per-race exchange rules, and selling a hull.
