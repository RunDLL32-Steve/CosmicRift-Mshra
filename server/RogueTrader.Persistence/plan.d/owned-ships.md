-   Owned ships (branch `claude/project-thread-kv5jsp`, Steve's request on PR #112, November 3, 2026). Profile schema 6 adds `OwnedShips` (hull id to parked condition, at most one of each hull). `ShipHullId` stays the active ship and `Ship` its condition. Invariants: the active ship is owned, an owned set always has an active ship, and the active entry is never parked. Migration V5ToV6 makes the schema 5 hull the only owned ship and changes nothing else. `FileProfileRepository` keeps a byte copy of any pre-migration file as `<id>.profile.schema<N>.json` before the first newer write, and never overwrites it. New transaction kinds: `BuyShip` (at a station, price from `IPriceSource.TryGetShipPrice`, refused with `ShipAlreadyOwned`) and `ShipDestroyed` (no station; the active hull only, else `ShipNotActive`; charges `DestructionPenaltyPercent` = 20% of the wallet rounded down, resets the active ship to the spawn, empties the inventory with negative item deltas (the client spills exactly those units into the sector as expiring `wreck:` piles via `WorldSimulation.DropCargo`), and keeps upgrades and owned ships). `SelectShipAsync` is a non-ledger change like ship saves and refuses `ShipNotOwned`. `SaveShipConditionAsync` now refuses hull 0. Evidence: `tests/Unit/Persistence/OwnedShipsTests.cs` and `tests/Unit/Trading/OwnedShipSessionTests.cs`. The 12 original hulls are derived by `server/RogueTrader.Trading/OriginalShipBuilder.cs` (oracle `tests/Unit/Trading/OriginalShipTests.cs`, regenerate with `RT_WRITE_DERIVED_SHIPS=1`) and sold at the Trading Outpost with the original same-race requirement (`IPriceSource.TryGetShipRequirement`, `ShipRequirementNotMet`). Stacked on G10 (#114) for `OriginalShipPhysics`. Not done: per-hull starting weapons (D-Cannon, Bio Cannon), radius, shield and energy decoding, per-hull sprites, and selling a hull.
-   Profile schema 7 (branch `claude/project-thread-h9uu0u`, review R1-2 on #118, November 4, 2026): `ShipCondition.CoordinateVersion` is saved per ship (`ownedShips` entries and `ship`). An absent field reads as `LegacyPracticeSector` (0), because every earlier save was in the 1,400-unit practice sector. Map saves write `MapPixels` (1). Migration V6ToV7 only advances the version. `RogueTrader.Trading.ShipPlacement.Position` starts a ship of the other coordinate version at the spawn, keeping its hull and heading, so every owned ship moves onto the map on its own. A sector saved before a failed profile write cannot make an old position pass for a map position. Evidence: `ProfileSerializerTests.Schema6Ships_ReadAsPracticeSectorCoordinates_EachOnItsOwn_AndSchema7KeepsEachVersion`, `OwnedShipSessionTests.EveryOwnedShipMovesOntoTheMapOnItsOwn_EvenAfterAFailedProfileWrite`.
