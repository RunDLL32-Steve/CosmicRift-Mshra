# Persistence implementation plan

Status authority: [master §14 persistent data](../../ROGUE_TRADER_2_PLAN.md#14-persistent-data), [§14.1 requirements](../../ROGUE_TRADER_2_PLAN.md#141-persistence-requirements), [M2](../../ROGUE_TRADER_2_PLAN.md#milestone-2--rogue-trader-core-gameplay), [M3](../../ROGUE_TRADER_2_PLAN.md#milestone-3--dedicated-multiplayer), and [§20.2 economy QA](../../ROGUE_TRADER_2_PLAN.md#202-economy-tests). Reconcile with [canonical feature catalog](../../docs/original-research/FEATURE_CATALOG.md), [field interpretation](../../docs/original-research/FIELD_INTERPRETATION.md), and [project progress](../../docs/development-log/PROGRESS.md). Reviewed October 13, 2026; no save/database runs.

Module status: **Engine-side persistence core implemented and unit-tested (October 15, 2026)**: immutable profile model, in-memory and isolated file repositories (atomic write, backup, checksum, quarantine, versioned schema with migration hook, single-owner lock) and an idempotent, compare-and-swap-protected transaction processor, per the [design](../../docs/architecture/PERSISTENCE_AND_TRANSACTIONS_DESIGN.md). It is data-agnostic: no original price, cargo or retention policy is encoded and nothing is wired into the running client/native gameplay, so no original-parity feature (RT-F068 etc.) or master M2 box is checked. Prototype client settings persistence does not satisfy gameplay persistence. M0/M1 engineering acceptance is complete; M2 save/load follows the validated original core-loop contract.

## Outstanding work

Repositories and transactions do not invoke that validator; historical backend schema, native ordering and wipe/exchange policy remain open.
- [ ] **In progress** — M2 persistence interfaces and isolated safe local save/load: the interfaces (`IProfileRepository`, `IPriceSource`, `ICargoPolicy`) and file/in-memory repositories are done and tested; catalog membership can now be checked through the optional validator; still open are validated original policy/price/cargo semantics, validation at repository/session boundaries and gameplay/UI integration.
- [ ] **Investigating** — RT-F035/RT-F043/RT-F049–RT-F050/RT-F054: hull exchange, death/drop, resale/spec/team prune and warp/transfer retention policy. Resolve original event ordering, raw flags, sentinel values and integer currency semantics before defining retained state. Client bank/pose is not progression state without evidence.
- [x] **Complete with evidence (engine-side)** — atomic inventory/currency updates, idempotent transactions, recoverable interrupted writes, versioned saves and explicit corruption handling. Evidence: `dotnet test tests/Unit/RogueTrader.UnitTests.csproj` on October 15, 2026 passed 210/210 (41 existing + 40 hull loader + 129 in [tests/Unit/Persistence](../../tests/Unit/Persistence), including the independent review's regressions for profile identity on disk, device names, unpaired-surrogate ids and parallel profiles): the six §20.2 economy bullets, 64-way concurrent double-spend, two processors on one repository, crash between temp and replace, truncated/bad-checksum/invariant-violating primary, both copies corrupt, newer/older schema left untouched, duplicate after restart, overflow and negative cases. Not covered: original data bindings, cross-process sharing, PostgreSQL, gameplay integration.

- [ ] **Not started** — M3 PostgreSQL schema/migrations and concurrency/transfer recovery through interfaces, followed by backup/recovery work in its master milestone. No database capacity/reliability is claimed.

Current composition: [TradingService](../RogueTrader.Trading/TradingService.cs) supplies docking decisions to this transaction core; `StationPriceTable` and `CatalogCargoPolicy` supply price/cargo policies. The Persistence project itself remains data-agnostic.

Completion history: no end-to-end gameplay persistence feature is complete. Prior [prototype acceptance](../../docs/development-log/2026-10-12.md#final-acceptance-and-preservation-reconciliation) verifies local flight/combat only. Documentation review reran no simulations/tests.
