## Shared motion source

`ShipMotion` factors the existing authority movement operation order, speed clamp and swept asteroid collision into the same fixed-60-Hz path used by prediction. Its motion-only adapter copies static asteroid geometry in catalog order and steps supplied position, velocity and heading. It does not tick an authoritative world or produce combat/cargo/mining effects.

Actual C6 authority comparisons include reverse thrust, turning, nonzero initial velocity, neutral drift and swept asteroid contact. Fourteen existing movement cases are included in the focused 52-case run.
