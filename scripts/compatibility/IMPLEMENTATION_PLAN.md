## Reproduction and boundaries

Root-owned Godot projects remain on SDK 8.0.419; this tooling uses isolated `.tools/dotnet10` SDK 10.0.401 and `.tools/compatibility/global.json`. Wrappers capture logs, use hidden owned helpers and bounded exits. Do not build helpers concurrently against the same derived server outputs. Parser/hash checks serve data features; simulations are reserved for completed gameplay needing behavior verification.

`run-data-loader.ps1 -Build`, `run-local-server-probe.ps1 -Build` and `run-arena-probe.ps1 -Build` **execute their probes** after building. `run-runtime-checks.ps1 -Build` compiles current source before running the focused handler checks; execution without `-Build` is rejected. `run-native-session-host.ps1 -Build` only prepares/builds; adding `-Start -DurationSeconds 120` starts the backend and forces a fresh compile. [write-session-config.ps1](SessionHost/write-session-config.ps1) supplies the same fresh NEW/provisional configuration to the host and fixed runtime checks. Reports hash the assemblies actually loaded. `prepare-native-profile.ps1` writes a fresh private HKCU test namespace and derived working executable but does not launch native UI; it is not a read-only inventory command. Follow the native plan for owned-process/profile cleanup.

`prepare-derived-source.ps1` records five derived source files: game/ping loopback bind, offline news/directory guards, VehicleMaker field 18, offline patch-announcement guard, and composed ScriptArena sell/capacity transformations. It starts from unchanged pinned upstream files and records source/working SHA-256. The host requires the ScriptArena provenance entry before staging or launch. `acquire-original-help.ps1` recovers five corroborating help files separately; `prepare-local-zone.ps1` retains the older core-data/no-BLO probe scope. `audit-rogue-package.py` and `check-vehiclemaker-fix.py` are offline readers with output guards. Canonical assets and upstream references remain unchanged; ignored `.tools/` and `artifacts/` evidence is not a redistribution license.

The October 14 focused regression has 35 checks: the retained baseline exposes exactly 16 expected defect failures and the fixed report has zero failures. RuntimeChecks performs no socket begins, arena polls, physics ticks or native-client launches. Separate healthy-host acceptance ran for approximately 10.25 seconds with zero clients, zero logged exceptions, recorded loaded-assembly hashes and unchanged staged original hashes. The earlier 120.17-second report remains historical socket/hosting evidence; its stdout contains 600 swallowed radar-routing exceptions, now addressed by RT-F395. Full native trading, gameplay and saving remain unverified.
