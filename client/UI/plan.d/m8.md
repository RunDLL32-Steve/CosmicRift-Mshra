# M8 HUD, station screen and save/load — client view

Parent: [Client UI implementation plan](../IMPLEMENTATION_PLAN.md). Queue item M8 in [TASK_QUEUE.md](../../../TASK_QUEUE.md) and [brief](../../../docs/tasks/m8.md). November 1, 2026.

-   **Boundary.** `RogueTrader.Trading.StationProfileSession` (Godot-free, unit-tested) owns the local `FileProfileRepository`, the `TransactionProcessor` and a `TradingService` that now also gates repairs and upgrades on docking. The client only renders `session.Profile` and raises requests; it never edits wallet, inventory or upgrades. Every transaction is saved before it is acknowledged, so there is no separate "save" step.
-   **HUD** (`FlightHud`): credits, cargo weight/capacity, held items and owned upgrades from the saved profile; a dock hint when inside the station's radius; profile status, save folder and a **Reload saved profile** button in the pause menu.
-   **Station screen** (`StationScreen`, key **F** / `station_dock`, Escape undocks): Market (buy 1, sell 1, sell all), Repairs and Upgrades tabs; the world does not tick while docked; refusals are explained (for example "not enough credits") and change nothing.
-   **World link.** The ship hold is built from the saved inventory, re-synced after every station transaction and reload (`CargoHold.ReplaceContents`), and in-space pickups are committed as one `GrantReward` per tick that gained cargo. Repairs restore hull through `WorldSimulation.RepairPlayerHull` with the station's provisional fraction.
-   **Save folder.** `user://profiles` (profile `local-pilot`), override with `--profile-dir=<path>`. A second client on the same folder, a corrupt save or a newer schema leaves station services offline with the reason shown; a corrupt save is never replaced with a fresh profile.
-   **Verification.** `--smoke-test` now runs `ClientStationSmokeTest` between the input and flight smokes against an isolated temporary save folder: wallet on the HUD, pickup commit, native F docking, buy/sell, repair, upgrade, explained refusal, reload from the pause menu, and a full reopen of the save folder with exact revision/wallet/inventory/upgrades. `--capture-station` captures the station screen.
-   **Not done.** Native HUD/store art and flow (RT-F025/F026), original station data (RT-F045/F047/F048/F049), hull/position persistence (hull is simulation state, not in the profile schema) and upgrade effects. M9 owns the exit/relaunch acceptance test. No original feature box or count changes.
