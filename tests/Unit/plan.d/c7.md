## Focused test source

`Prediction/PredictionTests.cs` contains 38 cases driven by integer-tick schedules against an actual `AuthoritativeSession`. Coverage includes exact motion/collision parity, authority isolation, delayed correction, suffix replay/convergence, lost input and snapshot, stale/duplicate snapshots, unchanged/jumping/regressing/unknown/premature acknowledgements, rejection atomicity, queue capacity recovery, non-reused identifiers, tick/sequence exhaustion, malformed or ambiguous controlled entities, snapshot/geometry copy isolation, destroyed hull and Fire as intent without local gameplay effects.

R1-1 adds two numeric-boundary cases: a finite input/catalog/baseline whose derived rotation becomes nonfinite must fail issue without consuming identifiers, and an overflowing replay must reject the correction atomically while retaining the queue for a valid correction. Both additions passed focused and full local verification.

`Prediction/PredictionNetworkScheduleTests.cs` adds three passing wire-codec/C6 schedule cases. The added schedules interleave ongoing input issue with useful delayed snapshots and replay: a 48-clock case compares future authority state before its snapshot without a terminal correction; two 600-clock loss/reorder/blackout/queue-pressure cases explicitly refill caller lead and each apply 112 useful delayed corrections. The 41 prediction cases plus 14 movement cases form the 55-case focused selection; the completion unit run verifies the new cases.
