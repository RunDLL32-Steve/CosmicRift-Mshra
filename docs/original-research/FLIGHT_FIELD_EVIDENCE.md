## 1. Unit chain proposed by the emulator

Three separate IOS code paths use the same units. They agree with each other and with the wire types, which is the strongest scaling evidence available in the cloud. They are still emulator code, written against the native client, not a measurement of it.

| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Position     | `ZoneServer/Protocol/Helpers/Objects.cs:31` `Int16 positionX`; bot clamps to `(Level.Width - 1) * 16` and tiles are `position / 16` (`MovementController.cs`, collision block)                                            | 1 unit = 1 pixel; 16 pixels per LVL tile                 | VERIFIED emulator; RECONSTRUCTED native, medium                     | The Rogue LVL is 1999 tiles wide, 31,984 px, which fits Int16 (max 32,767). Owner recollection, November 2, 2026: Steve (project owner, who played Cosmic Rift) confirmed in the project thread that reverse thrust "is the same backward as forward". This is COMMUNITY evidence (firsthand recollection, medium–high) and agrees with the chaos.nws statement and H10.

Reading adopted for the project: BackwardThrust −1 means "same as RollThrust" (RECONSTRUCTED from the text above plus the owner's recollection; medium). This records the decision only; no value changes in this PR. The prototype already uses equal forward and reverse thrust (`ShipPhysics.ForwardThrust` = `ReverseThrust` = 12000, NEW values). Still open for a local native run: whether reverse also has the same speed cap, and BackwardHyperThrust (f[211]), which nobody has described.

## 5. What a local run has to measure

Each item names the row it would settle. None of them can be done in the cloud container.

1.  Ship top speed in open space, in pixels or tiles per second, for Asp and Excelsior (sections 1–2, RollTopSpeed and the unit chain).
2.  Time to make one full turn for Asp, Hornet and Mastakith (RollRotate).
3.  Reverse speed cap compared with forward for one hull (section 4; equal thrust is now the owner-confirmed reading).
4.  Speed decay with no input in open space and in a Repair Dock (RollFriction, terrain 9).
5.  Hyper: how it is engaged, top speed reached and energy drained per second (HyperTopSpeed, HyperThrust, HyperEnergyCost).
6.  Which terrain indexes the Rogue LVL uses (queue G6 reader), to close section 3.

Until then the scale and every fallback stay open, and the prototype keeps its NEW values.
